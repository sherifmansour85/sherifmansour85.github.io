Set up your logo signature (once)

Email links (“Open in Outlook”) can only carry plain text, so the Hayakkom logo can't travel inside them. Put the signature in Outlook itself and every email you send carries the logo automatically.

  1. Click Copy signature below.
  2. Outlook on the web: ⚙️ Settings → Account → Signatures → New signature. Outlook desktop: File → Options → Mail → Signatures… → New.
  3. Paste, name it “Hayakkom”, and choose it as the default for new messages and replies/forwards. Save.
  4. Untick the box below so the Hub stops adding the text version (otherwise you'd get two signatures).
